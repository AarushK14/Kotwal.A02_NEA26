# Primal Archer - 2D Platformer

A 2D platformer game built in C# with Unity as my A-Level Computer Science NEA (non-exam assessment).

## Features
- Player movement
- Enemies
- Health system
- Collectibles
- Buffs and debuffs
- Timed levels
- Scoring
- Multiple levels

## Built with
- C#
- Unity
- MonoDevelop

## What I learned
- Applying object-oriented programming (classes, inheritance, encapsulation) to a larger project
- Planning, building and testing a game from start to finish
- Using Git/GitHub to manage my code

## How to run
1. Clone this repository.
2. Open the project folder in Unity.
3. Open the main scene and press Play.

## Controls
W/A/D to move, Space to jump, click to shoot
